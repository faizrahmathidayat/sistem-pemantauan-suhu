# Modul Hak Akses (Role dan Izin) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Setiap user punya satu role; role menentukan fitur mana yang boleh dipakai; role dan user dikelola dari aplikasi; semua halaman dan endpoint dijaga izin.

**Architecture:** Daftar izin adalah enum di kode (`Permission`). Role disimpan di tabel `roles`, pemetaan role-izin di tabel `role_permissions`, `users.role_id` menunjuk satu role. Tiap izin didaftarkan sebagai Gate Laravel sehingga route memakai `can:<izin>` dan Blade memakai `@can`. Role sistem "Administrator" otomatis memiliki semua izin.

**Tech Stack:** Laravel 13, PHP 8.4, Blade + Tailwind 4, PHPUnit 12 (SQLite in-memory), MySQL untuk dev.

**Spec:** `docs/superpowers/specs/2026-11-09-hak-akses-design.md`
